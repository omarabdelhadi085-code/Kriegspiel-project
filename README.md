# Kriegspiel Project

A modern Java implementation of the 'Game of War' (Le Jeu de la Guerre), engineered for PvE strategy.

## 🚀 Key Features
*   **Heuristic AI:** Features a custom 'Desperation Mode' AI that evaluates board states and maintains network connectivity.
*   **Thread-Safe Engine:** Custom rendering system using concurrent collections to prevent UI freezing.
*   **PvE Mode:** Full standalone single-player support.

## 🛠 Tech Stack
*   **Language:** Java 17+
*   **GUI:** Java Swing
*   **Build:** Maven

## 🎮 How to Play
Objective: Destroy the enemy Arsenals or eliminate their forces while keeping your own units connected to your supply lines.
